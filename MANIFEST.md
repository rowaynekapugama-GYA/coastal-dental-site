# Upload parts for GitHub

The site is 432 files and GitHub's web uploader takes 100 at a time,
so it is split into 6 parts. Upload them in order.

For each part: unzip it, open the folder, select everything INSIDE it,
and drag that into GitHub. Do not drag the part folder itself.
